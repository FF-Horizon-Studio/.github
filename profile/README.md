## What I build

**Mobile apps.** iOS and Android from a single codebase, with accounts, sync and notifications, published and maintained on both stores.

**Web applications.** From the data model to the interface, shipped and maintained.

**Automation and internal tools.** Scripts, bots and integrations that remove manual work from processes that run on documents, languages and training.

**AI-assisted products.** Practical applications of language models inside real workflows, not demos.

## Stack

TypeScript · React Native & Expo · React & Next.js · Supabase & PostgreSQL · Node.js · C# & .NET · Python · Azure · Vercel
